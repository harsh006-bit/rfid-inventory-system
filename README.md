# RFID Inventory Management System

## Project Title
RFID-Based Industrial Inventory Management System using ESP32

## Description
This project is designed to manage and track inventory using RFID technology.  
It uses ESP32 microcontroller to detect RFID tags and trigger alerts using LED and buzzer.

## Components Used
- ESP32 (ESP-12E)
- RFID Reader (RC522)
- RFID Tags
- Buzzer
- LEDs
- Resistors
- Jumper Wires

## Working Principle
When an RFID tag is scanned, the system verifies the UID and shows output using LED and buzzer.

## Features
- Real-time inventory tracking
- Fast RFID detection
- Alert system using buzzer and LED
